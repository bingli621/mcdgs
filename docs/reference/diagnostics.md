# Diagnostics

Setups that study one part of an instrument, and what reads their results. Each module with a
`main` runs as `python -m <module> [--out FOLDER]`, and makes the files of one page of the
documentation. See [Source](../instruments/trex/source.md),
[Extraction guides](../instruments/trex/extraction.md) and
[Bender scan](../instruments/trex/bender-scan.md) for what they show for T-Rex.
