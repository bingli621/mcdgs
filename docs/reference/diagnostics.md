# Diagnostics

Setups that study one part of an instrument, and what reads their results. Each module with a
`main` runs as `python -m <module> [--out FOLDER]`, and makes the files of one page of the
documentation. See [Source](../instruments/trex/source.md),
[Extraction guides](../instruments/trex/extraction.md),
[Bender](../instruments/trex/bender-scan.md), [Guide transmission](../instruments/trex/guides.md),
[Brilliance transfer](../instruments/trex/brilliance-transfer.md),
[Beam monitor](../instruments/trex/beam-monitor.md),
[Choppers](../instruments/trex/choppers.md),
[Time-distance diagram](../instruments/trex/time-distance.md),
[Neutrons on sample](../instruments/trex/neutrons-on-sample.md),
[Masked source](../instruments/trex/masked-source.md),
[Incident energy](../instruments/trex/incident-energy.md),
[Elastic resolution](../instruments/trex/elastic-resolution-incoherent.md),
[Diffraction](../instruments/trex/diffraction.md) and
[Rotation scan](../instruments/trex/diffraction-scan.md) for what they show for T-Rex, and
[Source](../instruments/cspec/source.md) and
[Time-distance diagram](../instruments/cspec/time-distance.md) for CSPEC.
[Run McStasScript's diagnostics](../how-to/run-mcstasscript-diagnostics.md) has the code of
`guides_diagnostics`, and [Guide transmission](../instruments/trex/guides.md) its figures.
