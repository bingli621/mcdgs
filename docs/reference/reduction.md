# Reduction

[scippneutron](https://scipp.github.io/scippneutron/). It imports nothing else from `mcdgs`. See
[Incident energy](../instruments/trex/incident-energy.md) for how T-Rex uses it, and
[Elastic resolution](../instruments/trex/elastic-resolution-incoherent.md#sq-e) for the
normalization of S(Q, E).
